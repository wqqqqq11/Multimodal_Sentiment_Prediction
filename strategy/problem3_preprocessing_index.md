# 问题三完整数据分析与预处理方案索引

问题三方案按职责拆分为以下文档：

1. `problem3_preprocessing.md`：任务边界、与问题一/二的依赖、已核验数据事实和总体原则；
2. `problem3_data_analysis.md`：标签、长度、零值、域偏移、模态冲突、原型可行性和泄漏分析；
3. `problem3_evidence_preprocessing.md`：字段转换、文本偏移、音视频时间映射、样本13修复、证据候选、原型与反事实准备；
4. `problem3_preprocessing_contract.md`：项目目录、输出字段、验收门槛、停止条件和执行顺序。

这四份文档共同构成完整方案。目前只完成设计，没有实现任何问题三预处理或模型代码。

## 核心决策摘要

- 主输入固定为附件2和附件4的 `aligned_50`；
- 复用问题二训练集缩放器和干净划分，但不复用附件3或缺失增强掩码；
- 问题三所有输出写入独立目录，不覆盖前两问；
- `privileged_text`不进入主输入，防止绕过Top-K证据瓶颈；
- 原型来源仅限附件2训练集；
- 附件4使用真实原视频建立词元—秒数—帧映射；
- 样本13采用“官方全零视觉主分支＋可验证修复候选分支”；
- 样本07和18执行50步截断专项核验；
- 附件4与附件2测试集的5条文本交集进入泄漏监控；
- 所有解释参数仅使用附件2验证集选择，附件4只执行冻结推理。
