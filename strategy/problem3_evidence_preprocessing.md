# 问题三证据映射与进阶预处理方案

本文规定基础变换、附件4证据定位、异常修复、稀疏证据候选、原型候选和反事实数据准备。它不包含模型结构或训练实现。

## 1 输入版本和字段转换

主实验固定使用附件2与附件4的对齐版。未对齐版只用于长度核验、时间映射辅助、样本13视觉修复候选和敏感性分析，不与对齐版在主输入中直接拼接。

| 字段 | 输出dtype | 规则 |
|---|---|---|
| `input_ids` | `int32` | 保持赛方词元编号，不缩放 |
| `attention_mask` | `bool` | 必须连续且与有效长度一致 |
| `token_type_ids` | `int8` | 保持原值 |
| `audio` | `float32` | 应用训练集缩放器 |
| `vision` | `float32` | 应用训练集缩放器 |
| 分类标签 | `int64` | 保持赛方编码 |
| 回归标签 | `float32` | 保持 `[-3,3]` 原尺度 |
| 掩码 | `bool` | 不使用浮点0/1替代 |
| 时间 | `float64` | 以秒保存，减少累计误差 |
| 帧号和位置 | `int32` | 内部使用0基索引 |

NaN或Inf若出现在观测位置，使用附件2训练集对应维中位数填补并设置 `nonfinite_repaired_mask`。若整条模态损坏，则保留样本、设置失败掩码，并禁止该模态进入证据候选。当前审计未发现非有限值，但规则仍需实现和测试。

每个划分同时保留原始值的只读审计副本、缩放后的模型输入、观测/自然零值/失败掩码，以及逐样本Winsorize比例、裁剪比例和漂移分数。

## 2 文本规范化和词元回映

文本只允许Unicode规范化、换行转空格和连续空白合并，不改写拼写、不删除停用词、不改变标点。保留：

- `raw_text`和`normalized_text`；
- 规范化字符到原始字符的双向偏移；
- WordPiece到规范化文本和原始文本的字符区间；
- WordPiece到空格词、子词组和特殊词元的映射。

使用与问题二文本编码器完全一致、版本固定的fast tokenizer重新分词。重新生成的词元编号、注意力掩码和分段编号必须与赛方 `text_bert`逐位置一致。若不一致，不覆盖赛方输入，而使用单调字符串匹配将赛方词元解码结果回映至原文，并保存 `token_alignment_confidence` 和差异原因。

## 3 附件4证据时间映射

### 3.1 映射记录

对附件4每个内容位置生成：

| 字段 | 含义 |
|---|---|
| `sample_id/position` | 样本编号和0基位置 |
| `token_id/token_text` | 赛方词元及可读形式 |
| `word_index/word_text` | 对应空格词 |
| `char_start/char_end` | 原始文本字符区间，右端开 |
| `start_sec/end_sec` | 原视频证据时间区间 |
| `start_frame/end_frame` | 可回看的实际帧范围 |
| `representative_frame` | 区间中心附近代表帧 |
| `mapping_method` | 强制对齐、子词继承或回退方式 |
| `mapping_confidence` | 0～1置信度 |
| `text/audio/vision_candidate` | 三模态候选资格 |
| `quality_flags` | 截断、全零、低置信度、修复等标记 |

### 3.2 文本到语音时间

1. 从附件4视频提取16kHz单声道音频，只用于时间对齐，不替代官方音频特征；
2. 使用原始英文转写执行词级强制对齐；
3. 缩写、数字、标点和口语词的处理规则固定并保存日志；
4. 同一空格词的WordPiece共享词级时间区间；如按字符比例细分，必须标记为插值而不是真实声学边界；
5. `[CLS]`、`[SEP]`和padding不生成原始证据区间；
6. 检查时间单调、非负、区间不反转且不超过视频时长。

强制对齐失败时按“邻近高置信词约束的局部插值→整句单调动态规划→内容位置比例换算”回退。任何回退都保存方法和置信度，比例换算不得伪装成精确边界。

### 3.3 时间到视频帧

视频帧映射使用顺序解码得到的真实PTS时间戳，不只依赖 `时间×FPS`。保存区间内起止帧、中心代表帧、人脸检测结果、主体选择和视觉质量。区间内无人脸时保留原区间并设置 `no_face_flag`，不能用其他时刻的“好看帧”替代。

附件4当前全部30fps，但仍采用PTS流程，以兼容容器时间戳异常和保证与问题一方法一致。

### 3.4 映射验收

检查三模态内容位置覆盖、位置到时间的单调性、所有区间位于 `[0,duration]`、WordPiece合并能否还原模型可见文本、帧号能否实际解码。随机人工核验至少5条，并强制覆盖样本07、13、18，生成文本—波形—代表帧联合核验图。

## 4 样本13视觉异常的双分支处理

样本13必须保留官方版本和修复候选，不能静默替换。

### 4.1 官方主分支

- 保留对齐版全零视觉；
- 设置 `vision_failure_flag=true`；
- 视觉位置不进入Top-K候选和视觉原型检索；
- 模型使用文本与音频完成预测；
- 解释结果说明官方对齐视觉特征不可用，但原视频仍可回看。

### 4.2 修复候选分支

1. 不采用错误的 `vision_lengths=1`，按最后非零位置推断长度18；
2. 使用未对齐视觉、真实视频PTS和词级时间边界，将视觉池化到50步接口；
3. 对其余19条正常样本执行相同重构，与官方对齐视觉比较；
4. 在附件2训练集确定重构参数，在验证集评价位置余弦相似度、序列MSE、非零覆盖率和预测稳定性；
5. 只有通过冻结阈值后，修复候选才可用于敏感性分析。

建议验收阈值为：健康样本中位位置余弦相似度不低于0.80，重构误差不超过训练健康样本分布95%分位，并且不制造非单调时间映射。不能根据样本13最终预测类别选择是否启用修复。

最终论文同时报告官方分支和修复分支的预测与解释变化。修复未通过时，最终提交使用官方主分支。样本16的异常仅存在于未对齐长度字段；主输入使用对齐版，因此只记录 `length_override_flag`。

## 5 稀疏证据候选数据

基本证据单元为 `(sample_id, modality, position)`。每个单元保存缩放后的真实特征、模态编号、绝对/相对位置、内容/观测/质量/失败掩码、文本字符与时间/帧映射、原始特征范数、局部变化率、映射置信度，以及能否进入选择器、原型库和反事实评价。

预测器不得额外接收完整原文池化向量、`privileged_text`、完整序列编码结果、全部选择概率向量或由全序列计算的标签相关统计。质量掩码可以限制候选集合，但不能承载未展示的情感内容。

预处理不确定最终K值，但为验证准备固定候选：K为3、5、8、10，有效候选比例为5%、10%、15%、20%，并支持全局Top-K与分模态Top-K。最终选择只依据附件2验证集的预测性能、充分性、完备性、稳定性和平均证据比例。

生成以下泄漏审计字段：

- `predictor_visible_mask`；
- `selector_visible_mask`；
- `metadata_visible_to_predictor`白名单；
- `full_context_feature_present`；
- `unselected_feature_zero_check`。

只要预测器能通过旁路读取未选位置，就必须判定内生证据瓶颈失败。

## 6 原型记忆候选

`prototype_source_manifest.csv`只包含附件2训练集，保存训练ID、位置、模态、分类标签、连续强度、强度分箱、候选有效性、原始文本、词元语境和特征质量。每个样本、每个模态设置候选上限，防止长样本垄断；自然零值、padding、结构位置、失败位置和非有限位置全部排除。

分别准备极性原型、7级强度原型和模态特定索引。预处理只准备候选和索引，模型隐表示、距离度量、聚类和medoid选择留到建模阶段。任何原型缓存都必须保留训练ID和位置。

验证、测试和附件4只允许检索训练原型。禁止使用验证集建库、写入测试标签、让附件4样本互相充当原型或根据附件4检索效果重选原型数量。

## 7 反事实一致性数据准备

对模型选出的证据集合 `E`，建模阶段需要：

1. 充分性视图：只保留 `E`；
2. 完备性视图：移除 `E`；
3. 稳定性视图：施加轻微语义保持扰动。

预处理保存构造规则、基线统计、固定种子和合法扰动范围，不预先假定模型会选择哪些位置。

| 模态 | 主要替代 | 对照 | 禁止做法 |
|---|---|---|---|
| 文本 | 固定 `[MASK]`策略并保存选择掩码 | 删除词元后的显示文本 | 随机替换成可能改变情感的词 |
| 音频 | 训练集同维中位特征或显式缺失向量 | 局部邻域插值 | 从附件4或同标签测试样本取值 |
| 视觉 | 训练集同维中位特征或显式缺失向量 | 局部邻域插值 | 用其他人的视觉片段替代 |

全零不能作为唯一基线。每个反事实输入同时带独立 `counterfactual_mask`，区分真实零值与人为删除。

稳定性模板包括标准化空间小幅高斯噪声、相邻位置 `±1` 时间抖动、同一词内部显示层扰动、非证据位置小比例遮蔽和不改变语义的模态幅值微扰。参数只由训练分布确定；验证集使用固定模板和固定种子；附件4只应用冻结规则。
