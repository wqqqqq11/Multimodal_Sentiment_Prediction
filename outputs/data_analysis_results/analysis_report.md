# 赛方数据集分析报告

数据来自 2026 年中国研究生数学建模竞赛 E 题“复杂场景下多模态情感预测的数学建模与算法设计”。
统计由 `data_analysis_code/run_all.py` 生成，明细表和分布图在各数据集子目录的 `tables` 与 `figures` 中。

## 1. 附件1：原始视频

附件1对应 `dataset01`，是问题1的原始材料：37 个 video_id、100 条标注、100 个 mp4。

标注表与视频文件一一对应：缺视频 0 条，无标注视频 0 个，无法解码 0 个，重复键 0。

情感强度 n=100，均值 0.340，标准差 0.806，中位数 0.333，范围 [-2.000, 2.667]。极性计数：正向 57，中性 25，负向 18。文字标签 annotation 与分数极性一致比例为 1.000。

转写词数 n=100，均值 19.32，标准差 10.53，中位数 18.00，范围 [5.00, 65.00]。视频时长 n=100，均值 11.15，标准差 5.20，中位数 10.35，范围 [2.64, 34.47] 秒，帧率 n=100，均值 29.60，标准差 1.47，中位数 30.00，范围 [23.98, 30.00]，文件大小 n=100，均值 0.99，标准差 0.73，中位数 0.80，范围 [0.18, 4.79] MB。

赛题给出的时长范围是 2.648–34.567 秒，实测落在该范围外的视频有 0 条（允许 0.05 秒容器计时误差）。分辨率以 1280×720 为主（56 条），其余为 640×360、480×270 等更低分辨率，帧率多数是 30，最低约 23.98。

同一 video_id 的片段数 n=37，均值 2.70，标准差 1.97，中位数 2.00，范围 [1.00, 9.00]。建模时样本键必须是 video_id + clip_id，不能只用文件夹名。

## 5. 跨数据集关系

附件1的 100 条里，只有 18 条能在附件2用 video_id + clip_id 找到，另外 82 条没有预计算特征。能找到的划分是：训练集 11，测试集 7，验证集为 0。

label-100.xlsx 的说明页写着这 100 条在原始 CMU-MOSEI 中属于训练集 64、验证集 10、测试集 26。那是完整语料上的划分，不是本次下发的 4850 条特征文件里的划分。说明页还确认极性为负向 18、中性 25、正向 57，与分数规则一致。

问题1要自行从 mp4 提取文本、语音、视觉特征并对齐，不能假设附件2已经给这 100 条准备好了特征。其中 7 条同时出现在附件2测试集，用附件1标签做特征抽查时不要拿这 7 条去调附件2的测试结果。

附件3里能配回附件2的 4 条全部属于测试集；附件4里能配回的 5 条也全部属于测试集。专项测试和附件2测试集有交集，但大部分专项样本是 4850 条之外的新片段。

## 6. 后续建模时直接可用的数据事实

情感强度是 [-3, 3] 的连续值，极性由符号决定，0 只算中性。分类评测用 Accuracy 和 F1，回归评测用 MAE 和 Pearson。

附件2类别不平衡，正向样本明显多于负向和中性，F1 需要看各类而不是只看准确率。

text 与 text_bert 二选一，text_bert 不是第四个模态。它的三行是 token id、attention mask、segment id。

对齐序列要单独处理第 0 步和尾部填充；未对齐序列要用各自的 length，不能把 500 步全部当成有效帧。

问题2的缺失是有效区间内部的连续全零，不是整模态删除。评估缺失率时应使用配回附件2之后的置零比例，而不是把填充零算进去。

问题3的 20 条视频与特征编号一致，解释结果里的时间位置应能回指到转写、语音长度或视频帧。
