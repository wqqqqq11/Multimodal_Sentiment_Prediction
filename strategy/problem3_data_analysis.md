# 问题三数据分析方案

本文是问题三预处理方案的数据分析分册。分析对象为附件2对齐版的官方训练、验证、测试划分，以及附件4的20条对齐/未对齐特征和原始视频。所有投影、阈值、缩放器和分箱规则只允许由附件2训练集确定。

## 1 文件与数据血缘

生成统一 `source_manifest.csv`，至少包含：

| 字段 | 含义 |
|---|---|
| `sample_id` | 附件2原ID或附件4编号 |
| `dataset/version/split` | 来源、特征版本和官方划分 |
| `feature_path/video_path` | 相对项目根目录的输入路径 |
| `sha256/file_size` | 源文件哈希和大小 |
| `schema_fingerprint` | 字段名、形状和dtype指纹 |
| `source_config_hash` | 上游配置与缩放器哈希 |
| `processing_status` | 成功、警告或失败 |

检查字段缺失、重复ID、跨版本文本差异、标签差异、同名文件内容差异以及按目录返回顺序隐式配对。附件4的特征、视频和编号必须通过显式主键连接。

## 2 标签与样本分布

仅在附件2执行：

1. 统计三划分三分类频数、比例和Wilson置信区间；
2. 统计回归标签的均值、中位数、标准差、分位数和边界比例；
3. 检查回归符号与三分类标签一致性，其中0只属于中性；
4. 绘制分类分布、强度直方图和分类×强度联合分布；
5. 比较训练、验证、测试标签分布，但不修改官方划分；
6. 生成训练集类别权重和分层抽样索引，验证集、测试集不做过采样。

已核验训练集负向967条、中性758条、正向1670条。模型评价必须同时报告Accuracy、Macro-F1、各类F1、MAE和Pearson。

## 3 长度、结构位置与截断

逐样本统计：

- BERT有效、内容和padding长度；
- `[CLS]`、`[SEP]`位置及注意力掩码连续性；
- 原文字符数、空格词数、WordPiece数和子词膨胀率；
- 是否达到50步上限、未覆盖字符范围和截断比例；
- 音频、视觉非零内容步数与文本内容长度的关系；
- 三模态各自可供Top-K选择的候选数量。

达到50步上限不等于一定截断。必须用同版本分词器重新编码并与赛方词元核对，确认原文存在未覆盖部分后才设置 `truncated_flag=true`。附件4样本07和18必须进入截断专项核验。

## 4 零值、缺失与失败语义

| 掩码 | 含义 | 可作为证据候选 |
|---|---|---|
| `content_mask` | 有效内容位置 | 是 |
| `structural_mask` | `[CLS]`、`[SEP]`等结构位置 | 否 |
| `padding_mask` | 尾部填充 | 否 |
| `observed_mask` | 内容区可用特征 | 是 |
| `natural_zero_mask` | 官方完整数据中的内容区全零 | 默认否 |
| `failure_mask` | 确认的提取或对齐失败 | 否 |
| `repaired_mask` | 通过验收的修复位置 | 仅修复分支可选 |
| `counterfactual_mask` | 人为移除的位置 | 动态生成 |

候选证据掩码定义为：

$$
C_{i,m,t}=M^{content}_{i,t}M^{observed}_{i,m,t}
\left(1-M^{failure}_{i,m,t}\right).
$$

结构位置、padding、非有限值和失败位置在Top-K前设为不可选。自然零值不做均值填补，也不能解释成某种情感证据。

## 5 数值异常和域偏移

问题三沿用问题二冻结的训练集缩放器：

1. 训练集0.5%和99.5%分位Winsorize；
2. 训练集中位数居中；
3. IQR缩放，退化维依次回退到标准差和1；
4. 标准化结果限制到 `[-8,8]`；
5. 变换后结构、padding和不可用位置恢复为精确零；
6. 附件4只应用参数，绝不重新拟合。

域偏移分析包括：

- 各模态超出训练分位范围的元素比例；
- 各维PSI或Jensen-Shannon差异；
- 能量、范数、稀疏率和训练PCA空间距离；
- 逐样本漂移排名和异常维贡献；
- Winsorize比例和绝对值8裁剪比例。

已核验附件4音频约0.97%、视觉约1.62%的有效元素落在训练分位范围之外；缩放后音频约0.28%的元素触及绝对值8裁剪，视觉没有触发。附件4无标签，漂移结果只能用于质量提示，不能用于反向选择变换。

## 6 模态一致性与冲突

在不改变原始特征的前提下：

1. 使用训练集拟合的投影计算位置级跨模态CCA、CKA或相关性；
2. 计算相邻 `±1` 和 `±2`位置的滞后相关，评估官方对齐的残余时滞；
3. 统计模态范数峰值重合率和冲突位置比例；
4. 按类别和强度区间比较模态结构；
5. 对附件4只应用冻结分析器，输出正常、弱一致、强冲突或不可用等质量标签。

这些指标只用于错误归因、原型质量和解释置信度，不直接作为情感标签。

## 7 原型库可行性

原型记忆只允许使用附件2训练集。分析每个“类别×强度区间×模态”的候选数量、类内紧致度、类间分离度、最近邻标签纯度、单样本候选占比和验证集最近原型覆盖距离。

强度预注册为：`[-3,-2)`、`[-2,-1)`、`[-1,0)`、`{0}`、`(0,1]`、`(1,2]`、`(2,3]`。候选不足时只能按预先规则合并相邻区间，不得根据附件4检索效果临时改箱。

原型最终应是可追溯的真实训练位置或medoid，而不是合成质心。附件2没有原始音视频，音频和视觉原型只能通过训练ID、对齐位置、标签、强度和相邻文本语境描述，不能声称可回放原始媒体。

## 8 泄漏与重复样本

`leakage_watchlist.csv`至少检查ID完全相同、规范化文本完全相同、特征近重复和视频哈希相同。

附件4已确认有5条与附件2测试集文本完全匹配：

| 附件4编号 | 附件2测试ID |
|---|---|
| 03 | `GAVpYuhMZAw$_$6` |
| 07 | `ChhZna-aBK4$_$8` |
| 08 | `2m58ShI1QSI$_$2` |
| 12 | `gE7kUqMqQ9g$_$2` |

这些样本不得进入训练原型库，不得用于选择K值、原型数量、强度分箱或反事实阈值。论文同时报告包含交集与排除交集的敏感性统计，但最终仍需对附件4全部20条输出结果。
