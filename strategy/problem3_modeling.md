# 问题三新版模型重构说明

## 针对首版结果的修正

首版验证结果为 Accuracy 0.5288、Macro-F1 0.5328、MAE 0.6402、Pearson 0.5726、
中性 Recall 0.6685，只有 Macro-F1 和中性 Recall 达标；FP16 权重约 23.14 MiB。

新版作出四项结构修正：

1. 使用赛方对齐文本特征和仅训练集拟合的 PCA，去除 BERT 参数；
2. 取消类别均衡采样，只保留温和类别权重，避免对中性类重复补偿；
3. 前几轮使用 Softmax，随后平滑过渡到 Sparsemax，降低模态过早塌缩风险；
4. 所有预测融合路径都乘以样本级模态门控，并加入单模态辅助分类和回归监督。

回归损失同时包含 Smooth-L1、Pearson、CCC 和分类回归一致性项。校准只在附件2验证集上搜索，
根据预测强度绝对值增强中性证据，并按强度方向调整正负极性分数。

## 可核验的验收规则

流水线以 Accuracy ≥ 0.65、Macro-F1 ≥ 0.52、MAE ≤ 0.55、Pearson ≥ 0.65、
中性 Recall ≥ 0.65 为联合验收门槛。只有五项同时满足才导出提交权重；因此“生成了模型文件”不会被误报为
“指标已经保证”。最终性能必须来自实际训练后的验证集记录。
